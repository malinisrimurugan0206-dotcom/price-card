# Responsive Product Pricing Cards

A modern, responsive SaaS pricing page with Basic, Pro, and Enterprise plans
and a Monthly/Yearly billing toggle.

## Features

- Three pricing plans: Basic, Pro, and Enterprise
- Pro plan highlighted with a "Most Popular" tag
- Monthly/Yearly toggle that updates prices dynamically
- "Save 20%" discount badge and yearly savings message on each card
- Working "Choose Plan" buttons with a confirmation message
- Smooth hover effects and subtle animations
- Fully responsive for mobile, tablet, and desktop
- Professional heading, subtitle, and footer

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, custom properties, animations)
- JavaScript (vanilla, no libraries or frameworks)

## How to Run

1. Download or clone this project folder.
2. Open the `pricing-cards` folder in VS Code.
3. Open `index.html` in your browser (double-click it, or use the
   "Live Server" extension and click "Go Live").
